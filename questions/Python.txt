Answer

result = ""
count = 1

for i in range(len(text) - 1):
    if text[i] == text[i + 1]:
        count += 1
    else:
        result += text[i] + str(count)
        count = 1

result += text[-1] + str(count)

print(result)

Output

a3b2c4

Python List Comprehension (Persistent Systems Interview)

List comprehension is a concise way to create a new list from an existing iterable (such as a list, tuple, string, or range).

Syntax
new_list = [expression for item in iterable]
Example
numbers = [1, 2, 3, 4, 5]

square = [num ** 2 for num in numbers]

print(square)

Output

[1, 4, 9, 16, 25]

Interview Questions on List Comprehension
1. What is list comprehension?

A concise way to create a new list from an iterable using a single expression.

2. What are the benefits?
Less code
Easy to read
Often faster than a traditional for loop
Pythonic style

Yes.

Yes.

Yes.

6. What is a constructor?

A constructor initializes an object automatically when it is created.

class Student:
    def __init__(self):

7. What is __init__()?

__init__() is Python's constructor method that initializes object attributes.

8. Can a class have multiple constructors?

Python does not support multiple constructors directly. You can simulate them using:

Default arguments
Variable-length arguments (*args, **kwargs)
Class methods

Example:

class Student:
    def __init__(self, name="Unknown"):
        self.name = name
self Keyword
9. What is self?

self refers to the current object of the class.

class Student:
    def display(self):
        print("Hello")
10. Is self a keyword?

No. It is a naming convention. You can technically use another name, but self is the standard.

class Student:

15. What is an instance method?

Works with object-specific data.

class Student:
    def display(self):

16. What is a class method?

Uses the @classmethod decorator and receives cls.

class Student:
    college = "ABC"

    @classmethod

        print(cls.college)
17. What is a static method?

Uses the @staticmethod decorator and doesn't access self or cls.

class Math:
    @staticmethod
    def add(a, b):
        return a + b

Polymorphism
29. What is polymorphism?

The same interface can behave differently depending on the object or input.

30. Types of polymorphism
Method Overriding
Operator Overloading
31. What is method overriding?

A child class provides its own implementation of a method defined in the parent class.

class Animal:
    def sound(self):
        print("Animal Sound")

class Dog(Animal):
    def sound(self):
        print("Bark")
32. Does Python support method overloading?

Not in the traditional sense. Similar behavior can be achieved using default parameters or *args.

Abstraction
33. What is abstraction?

Abstraction hides implementation details and exposes only essential functionality.

34. How is abstraction implemented in Python?

Using the abc module.

from abc import ABC, abstractmethod

class Shape(ABC):

    @abstractmethod
    def area(self):
        pass

Frequently Asked Tuple Interview Questions
1. What is a tuple?

A tuple is an ordered, immutable collection of elements.

Example:

t = (1, 2, 3)
2. Difference Between List and Tuple
List	Tuple
Mutable	Immutable
Uses []	Uses ()
Slower	Faster
More memory	Less memory
Methods like append(), remove()	Only count() and index()
3. Why Are Tuples Faster Than Lists?
Tuples are immutable.
Python can optimize their storage and access.
They require less memory.
4. Can a Tuple Be Modified?

No. Tuples are immutable.

t = (1, 2, 3)

# This raises an error:
# t[0] = 100
5. Can a Tuple Contain Different Data Types?

Yes.

t = (1, "Python", 3.14, True)
6. What Methods Are Available for Tuples?
count()
index()
7. Can a Tuple Contain a List?

Yes.

t = (1, [2, 3], 4)

The tuple itself is immutable, but the list inside it can still be modified.

8. When Should You Use a Tuple Instead of a List?

Use a tuple when:

Data should not change.
You want slightly better performance.
The data represents a fixed record (e.g., coordinates, database rows).

    except ConnectionError:
        attempt += 1
        print("Retry:", attempt)
        time.sleep(1)

Frequently Asked Exception Handling Interview Questions
1. What is an Exception?

An exception is an error that occurs during program execution and interrupts normal flow.

Example:

10 / 0
2. Difference Between Error and Exception
Error	Exception
Serious issue	Runtime problem
Usually cannot recover	Can be handled
Example: SyntaxError	Example: ValueError
3. Difference Between try and except
try	except
Contains risky code	Handles error
4. Difference Between finally and else
else	finally
Runs only if no exception	Always executes
5. Why Should We Avoid Empty Except?

Bad:

try:
    code

except:
    pass

Reason:

Hides errors
Difficult debugging

Exception

raise	except
