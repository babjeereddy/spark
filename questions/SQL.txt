What is DDL?

DDL (Data Definition Language) is a set of SQL commands used to define and manage the structure of database objects.

Think of a database as a newly constructed building.

CREATE → Builds the building.
ALTER → Renovates or extends the building.
TRUNCATE → Removes all furniture but keeps the building.
DROP → Demolishes the building completely.

Key Point: DDL changes the database schema, not the business data itself.

The IN operator checks whether a value exists in a specified list.

Topic 6 – HAVING Clause
What is HAVING?

HAVING filters grouped data.

WHERE filters individual rows.

HAVING filters groups.

Example

Departments with more than two employees.

SELECT Department,
       COUNT(*) AS EmployeeCount
FROM Employee
GROUP BY Department
HAVING COUNT(*) > 2;
Output
Department	EmployeeCount
IT	4
WHERE vs HAVING
WHERE	HAVING
Filters rows	Filters groups
Before GROUP BY	After GROUP BY
Cannot use aggregate functions directly	Can use aggregate functions
Example
WHERE
SELECT *
FROM Employee
WHERE Salary > 60000;
HAVING
SELECT Department,
       AVG(Salary) AS AvgSalary
FROM Employee
GROUP BY Department
HAVING AVG(Salary) > 70000;
Interview Question

Why can't aggregate functions normally be used in WHERE?

Answer

Because WHERE executes before grouping and aggregation.

Aggregate values do not exist at that stage.

What are SQL Set Operators?

Set Operators combine the results of two or more SELECT statements into a single result set.

Unlike JOINs:

JOIN combines columns.
Set Operators combine rows.
Types of Set Operators
Operator	Purpose
UNION	Combines results and removes duplicates
UNION ALL	Combines all results including duplicates
INTERSECT	Returns common rows
EXCEPT (SQL Server) / MINUS (Oracle)	Returns rows present in the first query but not in the second
Rules for Using Set Operators

Before using any Set Operator:

Rule 1

Both SELECT statements must return the same number of columns.

Rule 2

Columns must have compatible data types.

Rule 3

The order of columns must be the same.

Example

Correct

SELECT EmployeeID, EmployeeName
FROM CurrentEmployees

UNION

SELECT EmployeeID, EmployeeName
FROM FormerEmployees;

Incorrect

SELECT EmployeeID
FROM Employee

UNION

SELECT EmployeeID, EmployeeName
FROM EmployeeHistory;

Different number of columns.

What are Window Functions?

A Window Function performs calculations across a set of rows related to the current row without collapsing the result into a single row.

Unlike GROUP BY, Window Functions return one output row for every input row.

GROUP BY vs Window Functions
GROUP BY	Window Function
Groups rows	Keeps all rows
One row per group	One row per input row
Aggregate result	Analytical result
Cannot display detail rows	Displays detail rows and calculations together
