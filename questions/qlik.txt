However, an unnecessary or complex synthetic key can cause:

Increased memory consumption
Complex data model
Unexpected associations
Incorrect results in some data models

29. Why do we use Set Analysis?

We use Set Analysis when we want a calculation to consider a specific set of records, independent of or in addition to the user's current selections.

Common use cases:

Current Year Sales
Previous Year Sales
YTD Sales
MTD Sales
Sales for a particular region
Sales excluding a particular region


$ represents the current selection state.
1 represents the entire data set, ignoring the current selections.
$1 represents the previous selection state.
$2 Selection before $1
$0 — Current Selection?
+= — Add Values In Set Analysis, += is used with a field assignment to add values to the existing set.

Sum({<Region += {'South'}>} Sales)
Keep the existing Region values and add South.

-= removes values from the existing set.
Sum({<Region -= {'South'}>} Sales)
Keep the existing Region selection, but remove South.


Most important examples

➡️ Current selection  Sum(Sales)

➡️ Current selection Sum({$} Sales)

➡️ All data Sum({1} Sales)

➡️ Previous selection Sum({$1} Sales)

➡️ Replace Region with South Sum({<Region={'South'}>} Sales)

➡️ Add South Sum({<Region += {'South'}>} Sales)

➡️ Remove South Sum({<Region -= {'South'}>} Sales)


Qlik Answers is a GenAI-powered conversational assistant in Qlik Cloud that allows users to ask natural-language questions and receive answers, insights, charts, and sheets from structured and unstructured data.

Qlik Assist is Qlik’s AI-powered conversational analytics assistant. It allows users to ask questions about their business data using natural language instead of manually building charts or writing expressions.

Simple example

Suppose your Qlik Sense app contains sales data.

You can ask:

“What are the total sales by region?”

Qlik Assist can understand the question and provide an analytical response, such as a chart or table.

You can then ask:

“Which region has the highest sales?”

A Qlik Knowledge Base is a collection of documents and information that Qlik Assist can use as a source of knowledge when answering questions.

Think of it as giving Qlik Assist a company-specific knowledge library.

Simple example

Suppose your company has these PDF documents:

Sales_Policy.pdf
Product_Catalog.pdf
Company_FAQ.pdf
Customer_Return_Policy.pdf

You can add these documents to a Knowledge Base.
